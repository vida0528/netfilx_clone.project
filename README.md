# Netflix Clone 🎬

A Netflix-inspired website built using HTML, CSS, and JavaScript. This project recreates the look and feel of the Netflix homepage, featuring movie posters, categories, and a responsive layout.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Clean and modern design
- Movie poster display
- Horizontal scrolling
- Responsive layout
